# 怪物数值调整

在 Godot 文件面板选中 assets/enemies/catalog.tres，Inspector 会显示全部怪物条目；展开需要修改的 EnemyStats 资源即可改数值并保存。也可以直接选中 assets/enemies/goblin.tres 等资源。目录引用的是游戏实际读取的同一份资源，不是副本，修改会影响使用该怪物的所有关卡。请保存后重开战斗查看结果；运行中的实例会复制基础资源，不会即时热更新。

基础数值分组：Display Name 名称；Max Health 生命；Experience Reward 经验；Damage 单次伤害；Move Speed 移速；Attack Range 攻击范围；Attack Interval 间隔。

外观与碰撞：Visual Scale 立绘缩放；Body Radius 移动碰撞；Frame Origin 立绘锚点。受击区域：Hurt Radii 为独立受击椭圆，零向量沿用默认；Hurt Offset 为受击中心偏移。

技能参数：治疗间隔与倍数、自爆倍数与范围、召唤间隔、雪怪远程伤害/范围/间隔；母蛛的蛛丝初始冷却/周期/耐久、喷卵初始冷却/周期/数量、死亡蜘蛛/虫卵数量均可编辑。虫卵的 Hatch Time 控制落地后的孵化等待时间。

这些是基础值，层数、游戏难度、强敌节点和遗物仍会按现有规则修正运行时数值。普通/强敌/首领基础金币现为6/10/14，原有层数和遗物金币加成继续生效。
