# 新敌人

地图 EnemySpawns 中选择 enemy_kind：shaman（萨满）或 beetle（异变甲虫），照常设置数量、波次与普通/困难版本。

打开 scenes/maps/new_enemies_preview.tscn 按 F6，可在真实战斗中测试两种新敌人；原有制作中的关卡不自动替换怪物。

萨满：生命48、伤害6、移速90、射程400、攻击间隔1.2秒、击杀经验6。300像素内后退，400像素外接近，中间保持距离。后退期间继续攻击与治疗。至少两次发射后，对其他存活且受伤的敌人中当前生命绝对值最低者治疗；不自疗，不复活，不超过最大生命。两次治疗之间至少2.4秒。无受伤友军时继续攻击，出现受伤友军后优先治疗。治疗量=最终单次伤害×4，基础24，与层数、节点和游戏难度的伤害加成同步。

异变甲虫：生命64、伤害5、移速110、攻击距离40、攻击间隔1秒、经验5。死亡动画第7帧爆炸，半径50像素（以双方世界坐标距离判定，边界包含），对玩家结算最终单次伤害×2，基础10。一次死亡只爆炸一次，不伤害友军。普通受伤无敌、护盾与转换无敌规则仍生效。

动画从上传的原图按4列逐行切分：萨满移动/攻击/治疗/死亡及治疗、法球特效各8帧；甲虫移动/攻击各8帧、死亡12帧。资源均在 assets/enemies/；战斗参数在 shaman.tres、beetle.tres，新增治疗与爆炸参数可直接在 Godot Inspector 调整。


## 死灵法师、骷髅、雪怪、魔纹巨像

刷怪点 enemy_kind 新增 necromancer、skeleton、yeti、golem。四种基础参数分别位于 assets/enemies/ 下同名 .tres；经验分别为7、0、8、8。测试入口 scenes/maps/four_enemies_preview.tscn，按F6试玩。

死灵法师：300像素内后退、400像素外靠近；攻击或召唤期间停步，每1.5秒可攻击，每9秒可召唤3只骷髅，召唤优先，在动画释放帧生成。第一次召唤在出生9秒后；不设额外召唤数量上限。召唤骷髅播放出生动画后才行动，不随法师死亡消失；经验0，参与波次清场判定，数值沿用当前层数/节点/游戏难度倍率，位置受地图边界限制。

雪怪：近战45像素优先，远程400像素，分别1.2/1.5秒冷却，攻击动作期间停步，间隔中继续追击。近战伤害12、远程8，分别套用战斗倍率。对玩家生命造成伤害后附加3秒减速，速度乘0.75；再次生效增加3秒但不提高减速比例。无敌挡下或护盾完全吸收的攻击不附加减速。转换时减速计时继续，不因换形态清除；新战斗不保留。界面显示SLOW剩余时间。

魔纹巨像：基础生命512、伤害16、速度60、距离55、攻击间隔2秒；16帧砸击动画在第10帧判定伤害。骷髅挥剑在第4帧判定。

雪怪冰块飞行速度为406.25像素/秒，比原325提高25%；其他法球速度保持325。骷髅生命48。哥布林/投石哥布林/小史莱姆/中史莱姆/大史莱姆基础伤害依次为6/4/2/4/6。巨像攻击按站姿高度等比放大并对齐脚底，避免不同图集分格造成缩小。
