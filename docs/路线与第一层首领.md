# 路线与第一层首领（当前版本）

每局5层，每层7排，保持170像素排距，路线卷轴高度1370。第1排2常规+1强敌随机排列，第7排1首领。第2—6排共15槽：1行商、1休憩、额外随机1行商或休憩、3常规、2强敌、2空位、2秘藏、2事件、额外随机1事件或常规。

第六排固定包含一个空位，另一个空位不同行、不相邻排；三处行商/休憩分布在不同列；秘藏彼此不同列；事件彼此不同列。默认向前同列连通，最终排汇入首领。额外恰好7条：2条同排双向+5条斜线；首排没有同排连线，每排最多2条额外连接（斜线计入出发排）。同排移动仍花5金币，空位所在排维持无横向连线，节点不能重复访问。生成器为缺口预留前进斜线，并校验所有节点可达；规则均由种子决定。

普通与强敌关卡按符合层数条件的关卡库分配，同一level_id整局不重复。库不足禁止开局；已有待制作地图仍作为独立占位关卡使用。事件按种子、层、排、列从符合层数的资源中抽取。

赤腹母蛛：基础生命1024、伤害20、移速55、攻击距离88、攻击间隔1.5秒、经验24；立绘缩放由0.55升至0.99，即增大80%。不再有生命阈值阶段。蛛丝初始冷却6秒，之后18秒一次，耐久60，不生成小蜘蛛。喷卵初始冷却14秒，之后24秒一次，复用施法动画，飞出3枚虫卵，随机落在中央64%的区域，优先距母蛛至少240像素并彼此分散；空间不足时采用候选中间距最大的落点。施法期间沿用免伤与停步规则，两个技能不同时播放，待动作结束释放已就绪的技能。冷却从施法开始计时，暂停/形态转换冻结期间不计时。

母蛛死亡动画结束立即生成3只小蜘蛛+5枚虫卵，再移除母体，防止误判清场。虫卵0.28秒落地后10秒孵化，每枚生成1只小蜘蛛。地图会等待全部存活卵/蜘蛛清理完毕。虫卵基础生命48、经验0；小蜘蛛生命112、伤害3、速度120、距离50、间隔1.2秒、经验0。

节点倍率：常规与宿命对决的生命/伤害/经验倍率均1；强敌生命/伤害1.25，经验1。保留原有层数倍率（生命/伤害每层+13%）、游戏难度倍率与遗物修正。旧kind=boss史莱姆的身份专属强化不变；第一层赤腹母蛛使用独立身份，不套用该强化。

修改入口：scripts/expedition/expedition.gd（路线），scripts/expedition/arena.gd（节点倍率），assets/enemies/spider_matriarch.tres、spiderling.tres、spider_egg.tres（基础数值），scripts/enemies/spider_matriarch.gd（技能与落点），spider_egg.gd（孵化）。

母蛛受击区域：独立椭圆，半径(140,108)、中心偏移(-1,-106)，匹配0.99立绘的主体范围。光刃扫掠与影近战共同使用；移动碰撞半径保持42，避免改变贴身攻击距离与寻路。
