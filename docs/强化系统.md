# 升级强化

以用户提供的技能表实现23项技能。踏影按确认后的每级10%、三级30%实现。

战斗内升级只即时提升生命上限和攻击力，不额外回复生命，不弹出强化。强化次数累积到胜利结算，点击“升级”卡片后暂停并三选一；每组选项来自四类中的三个不同类型，每类最多一个。满级技能退出候选池。候选使用独立种子，不消耗战斗随机序列；打开或刷新不会重抽。同一次获得多个等级时逐次选择，选择期间世界、形态计时、敌人、弹体与经验球全部暂停。最后一次选择后恢复战斗；清场后先拾取全部经验再显示结算，金币/遗物/升级独立领取，可以全部领取；本场多次升级连续选择。领取或放弃遗物并完成其他奖励后才能继续。

技能等级本局跨战斗保留，新开局清空，不占背包槽位。保留原有升级基础攻击/生命成长。没有增加表格以外的前置、互斥或强化。

贯日每次命中后对当前伤害乘0.8；长虹一级改乘0.9、二级不衰减。满蓄力日耀和起势均乘算；起势只消费一次，对整次挥击/整枚光刃生效。共灭消耗异形态印记，追加伤害不再次触发印记。汲取按影形态攻击及影蚀的击杀计数，1/2/3级每3/2/1杀恢复1点生命。压制减速不叠强度，重复命中刷新3秒。

破晓排除首领；起势/共生等均在转换完成时生效。时长调整从下一段形态生效，不截断当前动作，默认20秒，单独增加/减少最多10秒。

已移除长辉棱镜、贯光符印、辉光刻印三件光刃遗物及其战斗初始化加成；原有图集编号不重排，其他遗物图标不受影响。

主要修改入口：scripts/upgrades/skill_catalog.gd（名称、类型、等级上限、说明与抽取），scripts/upgrades/upgrade_picker.gd（选择界面），Expedition.upgrades（本局技能等级）。
